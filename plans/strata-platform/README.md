The supported first release is self-host-first, with persistent native accounts, useful local workflows and operator setup/upgrade/backup/restore guidance. Hugging Face is optional. Company hosting is available only by explicit request; public SaaS signup and automated subscriptions are deferred.

Actual custom-model data, conversions, experiments, weights and scientific claims remain exclusively Claude Code-owned. Platform contributors use synthetic fixtures. Preserve protected-data/custody restrictions, accepted scientific and exact wire approvals, human secret boundaries and explicit paid-execution/production gates. Publishing this plan does not change repository licenses, implement these capabilities or make the platform ready for testing.
