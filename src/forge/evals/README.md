# forge.evals

Experiment runner composing prompt × model × dataset × graders. Graders (exact match, JSON similarity, LLM-as-judge, pairwise, semantic), standard metrics (accuracy, F1, BLEU, ROUGE), Markdown/HTML reports, parameter sweeps, a named experiment registry, trace replay against current code/model, and a CI eval-regression gate with absolute and relative thresholds.

> Implementation pending. See `docs/roadmap.md` for current status.
